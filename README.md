# 2D Platformer

Jump, run, and explore in this classic 2D platformer! Navigate challenging levels filled with platforms, obstacles, and precise jumps. With smooth controls and engaging level design, it's a fun test of skill—enemies coming soon!

## Please download and watch the "demonstration.mp4" for gameplay.
Please note that the demonstration does not take up the entire screen because of some issues with the screen recorder. The game itself does not have any such issues.
